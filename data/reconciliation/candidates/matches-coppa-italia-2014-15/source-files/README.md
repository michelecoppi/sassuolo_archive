# Materiali sorgente

Il pacchetto non redistribuisce copie di articoli o PDF di terzi. Gli URL diretti, il ruolo di ogni fonte, la data di verifica e le divergenze sono registrati in `SOURCES.md` e `discrepancies.csv`.

La fonte ufficiale primaria disponibile è il Comunicato Lega Serie A n. 26 per il terzo turno; per i dettagli non contenuti nei comunicati sono state incrociate cronache coeve e archivi partita autorevoli.
